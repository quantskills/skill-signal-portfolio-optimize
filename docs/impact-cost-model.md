# 冲击成本模型：评审材料（未实施）

状态：**评估结论为"暂不实施"**，供决策参考。
日期：2026-09-26。相关证据：`experiments/tsplit_resel300_study_v1/reports/tsplit_impact_cost.md`、
`reports/tsplit_structural.md`、`reports/时间切分验证_2024调参_2025-2026验证.docx`。

## 1. 现状

优化器第 2 阶段的目标函数是**线性成本**：

```
min  c · Σ t_i + λ‖w − w_ref‖²      s.t. t_i ≥ |w_i − w_i^prev|, 硬约束不变
```

`c = 7bps`（单边），执行端 stockdemo 另按双边 1.4‰ 扣费。两者都是**线性**的，
即"成交金额越大成本成正比"，忽略了冲击成本随参与率**次线性上升**的事实。

## 2. 事后核算实际量级（已做）

在 stockdemo 成交明细上叠加 ADV 平方根冲击：

```
impact_i = η · σ_i · sqrt(Q_i / ADV_i) · Q_i        （元）
σ_i = 前 20 日收益波动，ADV_i = 前 20 日日均成交额（均 shift 1，无前视）
```

| η | 年化冲击成本（1e8 组合，换手 ~4%/日） |
|---|---|
| 0.3 | 2.0 ~ 3.1% |
| 0.5 | 3.3 ~ 5.2% |
| 1.0 | 6.5 ~ 10.5% |

对照：现有线性成本约 1.4%/年（10×/年 单边换手 × 1.4‰）。**即冲击成本已与线性成本同量级甚至更大**，
且小盘/低 ADV 个股贡献主要部分（参与率中位 ~5e-4，但 p90 达 ~1e-3）。

## 3. 若写进优化器：怎么做

目标函数加入凸项：

```
min  Σ [ c · t_i + η · σ_i · sqrt(AUM / ADV_i) · t_i^{3/2} ] + λ‖w − w_ref‖²
```

- `t^{3/2}` 在 `t ≥ 0` 上**凸**（指数 1.5 ≥ 1），CVXPY 可直接写 `cp.power(t, 1.5)`；
  Clarabel 支持 3 维功率锥，也可显式展开为 `sqrt(t·u), u ≥ t²`（旋转二阶锥 + 功率锥）。
- 需要新增输入：每个调仓日的 `σ_i` 与 `ADV_i` 面板（可由 `market.parquet` 的 `amount`/`close` 现算，
  但会引入新的数据依赖与缓存指纹）。
- 需要标定：η（文献 0.3~1.0）、AUM（外生，写进配置）、以及是否对参与率设上限（如 >10% ADV 直接禁买）。

## 4. 预期影响与风险评估

| 维度 | 评估 |
|---|---|
| 对最优换手 | 会**下降**（边际成本随规模上升），方向上支持当前的 v2 默认（TE6+换手12%） |
| 对配置排序 | 事后核算显示低换手档优势扩大；由于 v2 已选择低换手，**在引擎内实现的边际收益显著小于 v1 时期** |
| 与已发布结果可比性 | **破坏**——所有既有跑次都按线性成本选组合，引擎一改就无法与历史结果直接对比 |
| 求解负担 | 目标函数多 n 个功率锥项（n≈5000），编译/求解时间预计上升（当前均值 ~13~45 s/期） |
| 标定风险 | η 取错会**系统性**改变换手水平（η 偏大会过度抑制交易，偏小则无影响），需用真实成交回溯标定 |
| 规模敏感性 | 冲击 ~ sqrt(AUM)：1e8 时已在 3~5%（η=0.5），若 AUM 上到 5e8/1e9 会到 7~15%，**届时不实现反而失真** |

## 5. 建议的 rollout（若决定做）

1. 以配置开关形式实现，**默认关闭**（`cost_model.impact_eta: 0.0` = 旧行为），保证历史可复现；
2. 单元测试：与事后核算对同一组合的冲击金额一致；η=0 时解与旧版本逐位一致；
3. 先在**一个**评价集上对比"开关开/关"的选择差异，确认最优换手与排序变化方向；
4. 再跑一遍方案 A 的 15 评价框架，确认排序稳定后再考虑设为默认；
5. 标定 η：用历史成交流（若可得）或按"成交价 vs 决策价"的滑点反推。

## 6. 结论

- **现在不必做**：v2 默认（TE6 + 换手 12%）本身就是抗冲击成本的配置，事后核算已把这一维度纳入选参依据；
- **触发条件**：AUM 计划 ≥ 5e8，或换手结构变化（如引入日内/更高频调仓）导致参与率显著上升；
- 真正影响更大的仍是**信号端**：现有 4~5 个模型彼此排名相关 0.84~0.91，集成为负向结果
  （见 `reports/tsplit_ensemble.md`），下一步应寻找**低相关的新 alpha 源**，而不是继续在参数与成本侧加杠杆。
